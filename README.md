# Question Modal 问卷弹窗

## 快速注意

- 安装/重装后，宿主会以「禁用」状态创建工具条目，请为需要使用它的智能体手动启用
  `question_modal`（设置 → 工具，或 `agent.json → tools.builtin_tools.question_modal.enabled`）。
- QwenPaw 2.3.x 需在运行配置中手动关闭「代码模式（Code Mode）」，
  否则问卷卡片可能无法正常渲染或交互。
- 若智能体仍用文字罗列选项而不弹问卷，可在其 `SOUL.md` 中补充：
  > 需要用户做选择、二选一/多选一、裁定阻断项或确认范围时，必须调用 `question_modal` 收集答案，
  > 禁止在正文罗列选项后等待手打回复。

---

给 QwenPaw 智能体用的**对话内阻塞式问卷**工具。

当智能体需要你在方案间做选择、确认范围、或拍板阻断项时，会调用 `question_modal` 工具，
在对话里渲染一张可点选的多页问卷卡，暂停等待，拿到结构化答案后继续推理。

**核心价值：把「选择题」从打字变成点选。**
纯文字选项无法点选、容易漏答、格式易被模型写歪；问卷卡把选项变成按钮，
一次问清、结构回传、无需复述。

## 核心功能

### 题型与作答

| 类型 | 说明 |
| --- | --- |
| `single` | 单选（点选即替换） |
| `multi` | 多选，**回传为数组**；二选一场景请用 `single` |
| `text` | 自由问答输入 |

- 每道选择题自带**「其他」文本框**，可填自定义答案；问卷末页另有独立的**「其他意见」**输入框。
- 「其他」框与末页均可**添加附件**，走宿主同一上传端点，大小/类型规则与输入框一致。
- 选项自动编号，仅便于口述定位，**回传仍是选项原文**。

### 推荐标记（`recommended`）

给选择题标注推荐项，被推荐选项左侧显示「AI 推荐」徽章：

```json
{"type": "single", "title": "用哪个方案？", "options": ["甲", "乙"], "recommended": "乙"}
{"type": "multi",  "title": "包含哪些模块？", "options": ["A", "B", "C"], "recommended": ["A", "C"]}
```

- 值是选项原文，多选用数组。
- 徽章在任何模式下都显示，仅作提示，不影响作答。
- ⚠️ `options` 必须保持**纯字符串数组**，推荐标记写在题目的 `recommended` 字段上，
  不要塞进 `options` 元素。

### 条件题（`showIf`）

后一题依赖前一题答案时做动态联动，选中前置选项后该题才出现：

```json
{"q0": ["用 pm 设计器做表单"]}
```

- 键可写序号（`q0`/`q1`）或题目原文；值支持字符串或数组（数组 = 任一命中即显示）。
- 未被选中的分支自动跳过：**进度分母 = 可见题数**，隐藏题答案不会回传。

### 三种驱动模式

卡片顶部开关，按卡片独立记忆，互不影响：

| 模式 | 行为 | 调用模型 |
| --- | --- | --- |
| **自动分析** | 逐题分析 → 自动填入推荐 → 翻页 → 末页自动提交 | 是，每题一次 |
| **只用推荐** | 直接采纳 `recommended` 标注 → 填入 → 翻页 → 提交 | **否，零请求** |
| **人工** | 由你手动作答 | 仅在你点「开始分析」时 |

- 两种自动模式均可点「⏸ 停止」随时接管，再点「▶ 继续」恢复；
  关闭页面后问卷仍会继续作答并提交，重开时从中断处恢复。
- 「只用推荐」下若某题既无推荐也无缓存，该题会被跳过并标注，流程不会卡住。

### 严格作答闸门

人工模式下，未作答的题不会被静默跳过：

- 当前题既没选、也没显式跳过时，点「下一步」或「提交」一律无效，
  卡片内会提示第几题未选及可用按钮。
- 想跳过必须显式点击**「跳过本题」**，或在末页点**「跳过并提交」**。
- 因此「答了一半却整卷交上去」从界面上不可能发生。

### 设置面板

工具栏「问卷设置」按钮打开居中弹窗，两层作用域：

- **会话覆盖**：模式 / 模型 / 提示词模板 / 携带上下文 / 并行分析，
  在卡片上改即只改本会话。
- **全局默认**：同类设置 + 人工模式提醒 / 单题分析超时 / 等待提示阈值等，
  只能从设置面板改。

卡片与设置页共用同一份生效配置（会话覆盖 > 全局默认 > 内建），不会两处显示不一致。

## 回传格式

```json
{
  "answers": {
    "q0": {"type": "single", "value": "选项 A", "other": "", "skipped": false,
           "attachments": [{"url": "/media/xx_doc.pdf", "file_name": "doc.pdf", "size": 2048}]},
    "q1": {"type": "multi",  "value": ["X", "Y"], "other": "", "skipped": false},
    "q2": {"type": "text",   "value": "自由输入", "other": ""}
  },
  "other": "",
  "attachments": [{"url": "/media/yy.png", "file_name": "yy.png", "size": 1024000}],
  "skipped": false
}
```

- `answers[*].attachments` = 该题「其他」框下的附件；顶层 `attachments` = 末页「其他意见」的附件。
- 跳过整份问卷：`{"skipped": true}`
- 跳过某一题：该题带 `skipped: true`，问卷继续。

## 环境要求

- QwenPaw `>= 2.0.0`（已在 2.2.x 验证）。
- QwenPaw 2.3.x 需关闭「代码模式」，详见顶部「快速注意」。
- 运行期无第三方 Python / npm 依赖。

## 安装

控制台 → 插件 → 安装，或：

```bash
qwenpaw plugin install question-modal-2.4.3.zip
```

安装后的启用与 QwenPaw 2.3.x 代码模式设置，见顶部「快速注意」。
